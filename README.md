# Omnidays – Obsidian Plugin

Omnidays is a plugin for Obsidian (https://obsidian.md) which shows the number of days since / until a specified date in your notes.

This plugin looks for code blocks with the `omnidays` code type.
It reads the `date` field and shows the days with reference to "today".

## In Development

Please note that this plugin is still in development and not ready for use yet.
